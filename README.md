# Gryd site

Production codebase for gryd.energy. Next.js App Router, React 19, Sanity for content.
The Hub is built: projects listing, project case study, Knowledge Hub listing with a
working category filter, article page, and news listing.

Design follows direction G from the hub prototype at
`~/Desktop/Gryd/gryd-homepage/hub-directions/g/`.

## Running it

```
npm install
npm run dev
```

The site runs in **mock data mode** by default. No Sanity credentials are needed.
Content comes from `src/lib/mock.ts`.

## Connecting Sanity

Set these in `.env.local` and the same functions read Sanity instead of the mock file.
Nothing else changes: `src/lib/content.ts` is the only switch.

```
NEXT_PUBLIC_SANITY_PROJECT_ID=
NEXT_PUBLIC_SANITY_DATASET=production
NEXT_PUBLIC_SANITY_API_VERSION=2026-08-18
```

Document types live in `sanity/schemas/`. Deploy them from a Sanity Studio that
imports `schemaTypes` from `sanity/schemas/index.ts`. The GROQ projections in
`src/lib/queries.ts` return exactly the shapes in `src/lib/types.ts`, so the mock
path and the Sanity path are interchangeable.

## Styling

Two global stylesheets, imported once in `src/app/layout.tsx`:

- `src/styles/tokens.css`, the locked brand palette, base type, nav pill, buttons, footer
- `src/styles/hub.css`, direction G, ported from the prototype `g.css`

No CSS framework and no CSS modules. The prototype is a single cascade of global
class names and porting it as global CSS keeps it byte for byte comparable against
the reference screenshots.

Fonts load through `next/font`: Borna medium and regular from `src/fonts/*.woff2`
via `next/font/local`, DM Sans via `next/font/google`. Both are exposed as CSS
variables (`--font-borna`, `--font-dm`) on the html element.

## Content rules

British English. No dash punctuation. The company name is written Gryd, never in
capitals. No cool hues anywhere in the palette, and no drop shadows. Solar Flare
`#FF5532` appears only on primary buttons and one word per headline.

The banned word list lives in the messaging guide digest at
`~/Desktop/Gryd/gryd-homepage/content-ref/messaging-guide-digest.md`. It is not
repeated here so that a grep for those terms across this repo stays clean.

## Content migration

Every article, case study and news item on the live gryd.energy site is in the
mock content layer. Nothing on the hub is a placeholder any more.

| Type | Count | Source |
| --- | --- | --- |
| Blog articles | 21 | `content-ref/article-*.md`, the verbatim 2026-08-13 capture of the live WordPress posts |
| Project case studies | 3 | Lower Farm Mews, St Ives, the 55 home independent analysis, same capture |
| News items | 20 | `content-ref/listing-news.md`, dates and outlets checked one by one against the listing |
| Featured images | 24 | Downloaded from the live WordPress media library into `public/img/live/` |

Where the pieces live:

- `src/lib/bodies.ts` holds the migrated article bodies as `Block[]`, keyed by
  slug, projects keyed `project:<slug>`. Generated by `docs/migrate-bodies.mjs`
  from the content-ref capture, then committed as data; it is not regenerated at
  build time.
- `src/lib/livePhotos.ts` maps each post and project slug to its real featured
  image in `public/img/live/`, with the intrinsic dimensions read off the file.
  Generated by `docs/migrate-photos.mjs`. The stock frames in `public/img/` are
  still the fallback for anything without a live image, and are still used inside
  article figures.
- `src/lib/mock.ts` consumes both. Card copy, categories, authors, dates and
  closing panels stay as they were.

Editorial handling. The text is Gryd's own published copy and was not rewritten
or shortened. Three mechanical changes only: dash punctuation removed, numeric
and currency ranges written as "to" and every other dash use turned into a
comma, and the company name normalised to Gryd. British spelling kept as
published, including headline capitalisation. Source tables have no Block type,
so a two column table becomes a `spec` block and a wider one becomes bullets
that repeat the column headings. Elementor renders some blocks twice on the live
site; exact repeats were dropped, and paragraphs the capture split across a hard
line break were rejoined.

Images are Gryd's own artwork or stock frames licensed by Gryd, taken from the
site's own media library at the original upload size where the full size file
resolved, otherwise at the largest served derivative.

Not recovered:

- `/fhs-briefing/`, the Gryd and Shoosmiths briefing page. It is a page rather
  than an article, so it is out of scope for the hub. The news row for it points
  at the differentiation article; it should point at the briefing page once the
  Future Homes Standard section at `/fhs` is built out.
- Nothing else. All 24 on-site articles and case studies were present in the
  content-ref capture, so no live refetch of body copy was needed.
